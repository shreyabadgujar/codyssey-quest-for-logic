# Codyssey visual asset pack

This package contains prototype-ready crops with the requested filenames and folder layout.

## Contents
- maps: 1 main world map
- islands: 10 island illustrations
- avatars: 4 explorer portraits
- accessories: 6 wearable items
- treasures: 6 quest/reward objects
- badges: 5 achievement emblems
- decorations: 5 decorative elements
- reference: original full contact sheet

## Important quality note
These files were cropped from one generated contact-sheet illustration and enlarged for convenient prototyping.
They are NOT individually rendered high-resolution source illustrations: some may retain a little parchment framing,
and they do not have transparent backgrounds. Use them to wire up the frontend and establish the visual direction.
For a polished final game, replace the map and individual sprites with separately generated high-resolution assets.

## Install
Copy the `assets` folder into:
`frontend/public/`

Your resulting paths will look like:
`frontend/public/assets/maps/aetheria-map.webp`
`frontend/public/assets/islands/array-archipelago.webp`

Do not rename files unless you also update the frontend asset paths.
